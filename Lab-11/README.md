# Lab 11 - 時鐘系統與PWM音樂播放

## 實驗概述
本實驗包含兩個主要應用：快速前進時鐘系統和PWM音樂播放系統。時鐘系統使用Timer中斷和外部中斷實現時間設定功能，音樂播放系統使用PWM和ADC實現可變音量控制。

## 硬體環境
- **開發板**: Nu-LB-NUC140
- **微控制器**: NUC140VE3CN
- **LCD顯示器**: 用於時鐘顯示
- **蜂鳴器**: 用於音樂播放（連接至PWM1_CH0）
- **ADC可變電阻**: 用於音量控制（PA7）
- **外部中斷按鈕**: 用於模式切換（PB15）

## 程式檔案說明

### Q1.c - 快速前進時鐘系統
**功能**: 實作一個可設定的時鐘系統，支援快速前進模式和時間調整功能

**主要特性**:
- 時鐘以15倍速前進（每15秒分鐘+1）
- 支援設定模式，可調整分鐘和秒數
- LCD顯示時鐘圖形和時間
- 使用Timer0中斷驅動時鐘更新
- 使用外部中斷切換設定模式

**操作說明**:
1. **正常模式**: 時鐘自動前進，每15秒分鐘+1
2. **設定模式**: 按下PB15按鈕進入設定模式
   - 按鍵1: 選擇編輯分鐘
   - 按鍵2: 選擇編輯秒數
   - 按鍵4: 增加5
   - 按鍵5: 增加10
   - 按鍵7: 減少5
   - 按鍵8: 減少10
3. **退出設定**: 再次按下PB15按鈕退出設定模式

**技術重點**:
- Timer0中斷處理（1Hz）
- 外部中斷處理（EINT1）
- LCD圖形繪製（時鐘指針）
- 按鍵掃描和防彈跳
- 三角函數計算（指針位置）

### Q2.c - PWM音樂播放系統
**功能**: 使用PWM播放音樂，並透過ADC可變電阻控制音量

**支援音樂**:
- **給愛麗絲** (Fur Elise): 按鍵5播放
- **小星星**: 按鍵6播放
- **Nokia 3310**: 按鍵4播放

**主要特性**:
- PWM頻率控制音調
- ADC讀取可變電阻值控制音量
- 即時音量調整（在播放過程中可調整）
- 多首音樂選擇

**技術重點**:
- PWM配置和頻率設定
- ADC中斷處理
- 音樂資料結構設計
- 節拍時間控制
- 音量動態調整

**音量控制原理**:
- ADC讀取值範圍: 0-4095
- 音量計算: `volume = 100 - (ADC_value / 409.6)`
- 音量範圍: 0-100（0為最大音量，100為靜音）

## 技術重點

### Timer中斷處理
- **Timer0**: 1Hz時鐘更新，每1秒觸發一次
- **時鐘邏輯**: 每15秒分鐘+1，每60秒秒數歸零
- **設定模式**: 在設定模式下暫停時鐘更新

### 外部中斷處理
- **EINT1**: 下降緣觸發，切換設定模式
- **防彈跳**: 使用硬體中斷避免按鍵彈跳
- **狀態指示**: PC12 LED顯示設定模式狀態

### PWM音樂播放
- **頻率範圍**: 使用Note_Freq.h定義的音符頻率
- **占空比**: 固定占空比，頻率控制音調
- **音量控制**: 透過PWM輸出使能控制音量

### ADC音量控制
- **採樣頻率**: 在音樂播放迴圈中即時採樣
- **動態調整**: 播放過程中可即時調整音量
- **數值映射**: 將ADC值映射到音量範圍

## 擴展應用
- 可增加更多音樂曲目
- 可實作音樂播放列表
- 可加入播放/暫停功能
- 可實作時鐘鬧鐘功能
- 可整合RTC（即時時鐘）模組
- 可加入音樂節拍顯示

## 注意事項
- 時鐘系統使用快速前進模式（15倍速），非真實時間
- PWM音量控制需要適當的硬體連接
- ADC採樣需要在播放迴圈中進行，以實現即時調整
- 音樂資料需要正確的音符頻率定義
- 確保Timer中斷優先權設定正確
- 外部中斷需要適當的防彈跳處理
